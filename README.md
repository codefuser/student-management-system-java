# 🚀 Project Overview

A professional console-based **Student Management System** built using:

- ✅ Java
- ✅ JDBC
- ✅ MySQL
- ✅ Object-Oriented Programming
- ✅ DAO Design Pattern

This project performs full CRUD operations with validation and database connectivity.

---

# ✨ Features

✅ Add Student  
✅ View Students  
✅ Search Student  
✅ Update Student  
✅ Delete Student  
✅ Email Validation  
✅ Phone Number Validation  
✅ Duplicate Email Prevention  
✅ Loop-Based Console Menu  
✅ JDBC Database Connectivity

# ⚙️ How To Run

## 1️⃣ Clone Repository

```bash
git clone https://github.com/codefuser/student-management-system-java.git
```

---

## 2️⃣ Open Project

Open in VS Code.

---

## 3️⃣ Compile Project

```bash
javac -cp ".;../lib/mysql-connector-j-9.7.0.jar" App.java
```

---

## 4️⃣ Run Project

```bash
java -cp ".;../lib/mysql-connector-j-9.7.0.jar" App
```
